# Alfa Git

Desktop Git client for the folder where all your repositories live.

This repository hosts the website (GitHub Pages) and the downloads. The application's source code is
not published here.

## Download

Get the latest version from [Releases](https://github.com/while1is1/alfagit-releases/releases/latest),
or from [alfagit.com](https://alfagit.com/#download) with the install steps for each system.

- **macOS** (Apple Silicon): `Alfa-Git-*-mac-arm64.dmg`. The beta is not notarized by Apple yet: the first
  time, open it from Applications, then System Settings › Privacy & Security › **Open Anyway**.
- **Windows** (x64): `Alfa-Git-*-win-x64-setup.exe`. If SmartScreen stops it: **More info › Run anyway**.
- **Linux** (x64): `sudo apt install ./alfa-git_*_amd64.deb` on Ubuntu, Debian and derivatives, or the AppImage.

Git 2.30 or newer is required. Alfa Git checks for new versions on its own.
