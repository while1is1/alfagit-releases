# Alfa Git

Desktop Git client for the folder where all your repositories live.

This repository hosts the website (GitHub Pages) and the Linux downloads. The application's source
code is not published here.

## Download

Get the latest `.deb` from [Releases](https://github.com/while1is1/alfagit-releases/releases/latest) and
install it with apt:

```bash
sudo apt install ./alfa-git_*_amd64.deb
```

Linux x64 (Ubuntu, Debian and derivatives). Git 2.30 or newer is installed as a dependency.
