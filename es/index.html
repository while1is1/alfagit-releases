Por qué otro cliente Git

Casi todos los clientes Git asumen un repositorio a la vez.
Tu trabajo no.

Un par de servicios, una librería compartida, una app, algo legacy que nadie quiere tocar — todo en una carpeta. La pregunta casi nunca es "¿qué cambió en este repo?" Es "¿cuáles de mis repositorios tienen trabajo que olvidé commitear?" Alfa Git lo responde de un vistazo, no con un recorrido por veinte ventanas.

Workspace

Todos los repositorios de un vistazo

Apúntalo a una carpeta una vez. Alfa Git encuentra cada repositorio que hay dentro — worktrees, submódulos y repos anidados incluidos — y le pone a cada uno un punto de estado: cambios, conflictos, un merge o rebase en curso.

  • Workspace Changes: una línea por repo, primero lo que necesita atención — conflictos, un merge o rebase detenido, commits por traer
  • Fetch All sobre todos los remotos, con concurrencia limitada
  • Pestañas de workspace para tener varios proyectos a mano

Historial

Un grafo que muestra la estructura

Carriles y colores por rama, el autor en cada nodo, chips de ramas y tags. Los cambios sin commitear van arriba, y cada stash cuelga del commit desde el que se hizo.

  • Clic derecho para cherry-pick, revert, merge, rebase, reset o tag
  • Detalle del commit con sus archivos y su diff lado a lado
  • Rebase interactivo: arrastra para reordenar, squash, fixup, reword, drop
  • File History y Blame: cada commit que tocó un archivo, y quién cambió cada línea por última vez
  • Ctrl/⌘+F busca commits por mensaje, autor, rama, tag o hash

Cambios

Stage, diff y commit

Grupos merge, staged, unstaged y untracked — como árbol o como rutas — con diffs con resaltado de sintaxis que marcan las palabras exactas que cambiaron dentro de cada línea. Amend, stash de todo o de algunos archivos, y discard con una confirmación del propio sistema operativo.

  • Stage y unstage por archivo, o todo de una vez
  • Amplía el contexto alrededor de un cambio, o lee el archivo entero
  • Discard y clean, confirmados de forma nativa
  • Stashes parciales, amend, modos de pull

Revisión

Revisa una rama como un pull request

Elige una base y una rama para comparar: sus commits, cada archivo que cambia y el diff, antes de integrarla. Alfa Git simula el merge en memoria y te dice qué archivos entrarían en conflicto — sin tocar tu working tree.

  • Marca archivos como Viewed; si la rama vuelve a cambiar uno, vuelve a aparecer sin ver
  • Muestra un solo commit o un tramo, no solo la rama entera
  • Merge, squash o rebase desde la cabecera, como el botón de un pull request

Conflictos

Decide mirando, no leyendo marcadores

Cada lado de un conflicto es una tarjeta: qué le hizo al archivo y de qué commit viene, con un botón que dice exactamente qué va a hacer. Arréglalo a mano ahí mismo cuando ningún lado tiene razón.

  • Bloques en conflicto resaltados en el archivo de trabajo
  • Cada versión a una pestaña de distancia
  • Conflict 2 of 3 te lleva por el resto

Rebase

Un rebase que puedes seguir

Mientras un rebase está detenido, la cabecera dice qué se está rebaseando sobre qué y cuánto lleva — y el grafo marca el plan: lo que ya se aplicó, dónde se detuvo y lo que falta.

  • Se lee de los archivos de Git, así que funciona con un rebase que empezaste en la terminal
  • Te avisa antes de reescribir commits que ya están publicados

Editor

Un editor para el arreglo rápido

Monaco, por repositorio, para ese typo por el que no quieres cambiar de app. Crea, renombra y borra archivos, resuelve un conflicto y haz stage — o salta a tu editor o terminal de siempre con un clic.

  • Busca archivos y texto dentro de un repositorio
  • Abre en tu editor o en tu terminal

Terminal

Una terminal en cada repositorio

Tu propio shell, ya dentro del repositorio, justo bajo el grafo. Una pestaña por terminal, y siguen corriendo mientras el panel está oculto — Ctrl/⌘+J las trae de vuelta.

  • Sobrevive a recargar la ventana; al cerrar la app se cierra cada shell
  • Tu prompt tal cual, con los iconos de Nerd Font incluidos
  • O abre tu terminal de siempre en el repositorio

Por dentro

Hecho sobre Git,
no alrededor de él.

Sin librería de Git ni binario empaquetado. Alfa Git usa el Git que ya tienes instalado, así que lo que muestra es exactamente lo que dice git — y cuando algo falla, ves el error real.

Output
12:04:31 ✓ git status --porcelain=v2 -z · api-users · 38 ms
12:04:31 ✓ git log --pretty=format:… -n 200 · checkout-service · 51 ms
12:04:33 ✓ git fetch --prune origin · api-payments · 812 ms
12:04:40 ✗ git push origin main · exit 1
         ! [rejected] main -> main (fetch first)
  • Nunca un shell. Git corre con spawn(git, args[], { shell: false }); lo que escribes va después de --end-of-options o --.
  • Salida legible por máquina. --porcelain=v2 -z y separadores de campo, leídos por funciones pequeñas y testeadas.
  • Cuidadoso con carpetas grandes. Nunca entra en .git, se salta directorios pesados y limita cuántos procesos Git corren a la vez.
  • Lo destructivo se confirma. Discard, clean, reset y borrados los confirma el sistema operativo.
  • Solo local. Sin cuenta, sin nube, sin telemetría. Tu código no sale de tu máquina.

Preguntas frecuentes

¿De verdad es gratis?

Sí. Durante la beta todas las funciones son gratis, sin cuenta y sin tarjeta. Después de la beta, el precio será $15 USD al año, y avisaremos con bastante anticipación antes de que termine.

¿En qué plataformas funciona?

macOS en Apple Silicon (M1 o posterior), Windows 10 y 11 en x64, y Linux x64: un paquete .deb para Ubuntu, Debian y sus derivadas, y un AppImage que funciona en las demás distribuciones.

¿Cómo lo instalo?

Cada sistema tiene sus pasos en Descarga. En Windows, instálala desde la Microsoft Store: sin avisos y sin permisos de administrador. Mientras Alfa Git esté en beta la build de macOS todavía no está notarizada por Apple, así que macOS te pide confiar en la app una vez (Ajustes del Sistema › Privacidad y seguridad › Abrir igualmente).

¿Cómo lo actualizo?

En Windows la actualiza la Microsoft Store. En Linux (y con el instalador .exe de Windows), Alfa Git se actualiza sola: descarga las versiones nuevas en segundo plano y muestra Restart to update en la barra superior; se instala cuando haces clic. En macOS te avisa cuando sale una versión nueva y te trae a esta página para descargarla. Si te quedas varias versiones atrás, te pide actualizar para que no te pierdas nada. También puedes buscar en el momento desde Help › Check for Updates….

¿Necesito tener Git instalado?

Sí — Git 2.30 o superior. El .deb depende de él, así que apt lo instala si no lo tienes. Alfa Git usa tu propio Git, con tu configuración, credenciales y hooks, en lugar de traer uno propio. Prever conflictos en la revisión necesita Git 2.38 o superior; el resto funciona desde 2.30.

¿Mi código sale de mi máquina?

No. No hay cuenta, ni sincronización en la nube, ni telemetría. El único tráfico de red es el Git que tú pides (fetch, pull y push a tus propios remotos) y la consulta de versiones nuevas en GitHub, que no envía nada sobre ti ni sobre tus repositorios.

¿Qué cliente Git sirve para manejar muchos repositorios a la vez?

Alfa Git está hecho justo para eso. Abre la carpeta donde viven tus repositorios (un ~/Projects con servicios, librerías y apps) y lista cada repositorio que hay dentro — worktrees, submódulos y repos anidados incluidos— con su propio estado. Workspace Changes muestra cuáles tienen trabajo sin commitear, conflictos o commits por traer, y Fetch All los actualiza todos juntos.

¿Funciona con GitHub, GitLab y Bitbucket?

Sí. Alfa Git usa el Git instalado en tu máquina, así que hace fetch, pull y push a cualquier remoto al que Git llegue —GitHub, GitLab, Bitbucket, Azure DevOps o tu propio servidor— con tus llaves SSH y tu credential helper de siempre. No hay que iniciar sesión en nada.

¿En qué se diferencia de GitKraken, Fork o SourceTree?

Esos son muy buenos con un repositorio a la vez. Alfa Git está pensado para una carpeta con muchos repositorios: la escanea una vez y te muestra el estado de todos juntos, y luego te da un cliente completo por repo.

Descarga la beta para tu sistema

macOS

Apple Silicon (M1 o posterior)

Descargar para macOS .dmg · Apple Silicon
Beta

Esto es una beta, no una versión de producción. Alfa Git está en beta pública y todavía no está notarizada por Apple, así que la primera vez que la abras macOS dirá que no puede verificar la app. Le indicas a macOS que confías en ella una vez y desde ahí se abre como cualquier otra.

  1. Abre el .dmg y arrastra Alfa Git a Aplicaciones.
  2. Abre Alfa Git desde Aplicaciones. La primera vez macOS la bloquea: cierra el aviso con OK (no “Trasladar a la papelera”).
  3. Confía en ella: abre Ajustes del Sistema › Privacidad y seguridad, baja hasta Seguridad y haz clic en Abrir igualmente junto a “Se ha bloqueado Alfa Git”. Confirma con tu contraseña o Touch ID.
  4. Ábrela otra vez y haz clic en Abrir. Listo: macOS recuerda tu elección.
¿macOS dice que la app “está dañada”, o prefieres la terminal?

Es el mismo aviso de la beta con otras palabras. Quita la marca de cuarentena que macOS pone a las descargas y vuelve a abrirla:

xattr -dr com.apple.quarantine "/Applications/Alfa Git.app"

Actualizaciones: Alfa Git revisa si hay versiones nuevas y muestra vX.Y.Z available en la barra superior; te trae de vuelta aquí para descargarla. Reemplaza la app en Aplicaciones y confía en ella una vez más (solo mientras estemos en beta). Necesita Git 2.30+: xcode-select --install lo instala.

Windows

Obtener en Microsoft Store Microsoft Store · x64
Beta

Esto es una beta, no una versión de producción. En Windows, Alfa Git se instala desde la Microsoft Store: firmada por Microsoft, sin aviso de SmartScreen, y la Store la mantiene al día.

¿Ya la instalaste con el .exe? Desinstala esa copia primero desde Configuración › Aplicaciones, para no quedar con dos. Tus workspaces y tu configuración se mantienen.

Si tienes Control inteligente de aplicaciones activado (Windows 11), Windows lo bloquea sin opción de ejecutarlo: usa la Microsoft Store. Linux

x64 · Ubuntu, Debian y derivadas, o cualquier distro

Descargar el .deb AppImage (cualquier distro)
  1. Ubuntu, Debian y derivadas: instala el .deb con apt desde la carpeta donde lo guardaste: sudo apt install ./alfa-git_*_amd64.deb. apt instala Git si falta.
  2. Otras distribuciones: descarga el AppImage, hazlo ejecutable con chmod +x Alfa-Git-*.AppImage y ábrelo (necesita libfuse2).
  3. Para desinstalar el .deb: sudo apt remove alfa-git.

Actualizaciones: Alfa Git se actualiza sola y muestra Restart to update en la barra superior; el .deb pide tu contraseña para instalarse, como cualquier paquete.
