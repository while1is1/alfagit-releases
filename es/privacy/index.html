Política de privacidad

Última actualización: 2 de octubre de 2026

Alfa Git no tiene cuentas, telemetría, analítica ni publicidad. No recopila, vende ni comparte datos personales. Esta página explica qué guardan y qué envían la app de escritorio y este sitio.

La app de escritorio

Lo que queda en tu computador

  • Los workspaces que abres, los repositorios encontrados en ellos y tu configuración. Se guardan en una base de datos local en la carpeta de perfil de la app y nunca salen de tu computador.
  • El registro de los comandos Git que ejecutó la app vive solo en memoria, sin contraseñas ni tokens, y se pierde al cerrar la app.
  • Alfa Git no guarda contraseñas de Git. La autenticación la hacen Git y el credential helper o las llaves SSH que ya usas.

Desinstalar la app y borrar su carpeta de perfil elimina todo.

Lo que pasa por la red

  • Las operaciones Git que pides. Fetch, pull, push y clone se conectan a los remotos configurados en tus repositorios (por ejemplo GitHub, GitLab o tu propio servidor). A ese tráfico se aplican sus políticas de privacidad.
  • La búsqueda de nuevas versiones. Las copias descargadas desde este sitio le piden a GitHub (github.com y api.github.com) las versiones publicadas, al abrirse y cada pocas horas. En Linux, la versión nueva también se descarga desde GitHub. Estas consultas no llevan información sobre ti ni sobre tus repositorios; como cualquier petición web, GitHub ve tu dirección IP. La versión de Microsoft Store no las hace: la actualiza la Store.
  • Los enlaces que abres. Páginas como la web de un repositorio o la descarga de Git se abren en tu navegador.

Nada más: ni estadísticas de uso, ni reportes de errores, ni identificadores.

Este sitio

  • alfagit.com no usa cookies ni analítica.
  • Lo sirve GitHub Pages a través de Cloudflare y carga fuentes desde Google Fonts. Esos proveedores reciben tu dirección IP y datos del navegador para entregar la página, según sus propias políticas de privacidad.
  • Para que los botones de descarga apunten a los archivos más recientes, la página consulta a GitHub la última versión.
  • La pestaña de sistema operativo que eliges en la sección de descarga se recuerda en el almacenamiento local de tu navegador, solo en tu dispositivo.

Menores de edad

Alfa Git es una herramienta para desarrolladores y no está dirigida a menores. No recopila datos de nadie, tampoco de menores.

Cambios

Si esta política cambia, la nueva versión se publica en esta página con una nueva fecha.
