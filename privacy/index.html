Privacy Policy

Last updated: October 5, 2026

Alfa Git has no account, no telemetry, no analytics and no ads. It does not collect, sell or share personal data. This page explains what the desktop app and this website keep and send.

The desktop app

What stays on your computer

  • The workspaces you open, the repositories found in them and your settings. They are kept in a local database in the app's profile folder and never leave your computer.
  • The log of Git commands the app ran lives in memory only, with passwords and tokens removed, and is gone when you close the app.
  • Alfa Git does not store Git passwords. Authentication is handled by Git and the credential helper or SSH keys you already use.

Uninstalling the app and deleting its profile folder removes all of it.

What goes over the network

  • The Git operations you ask for. Fetch, pull, push and clone talk to the remotes configured in your repositories (for example GitHub, GitLab or your own server). Their privacy policies apply to that traffic.
  • The check for new versions. Copies downloaded from this website ask GitHub (github.com and api.github.com) for the released versions, when they start and every few hours. On Linux, a new version is also downloaded from GitHub. These requests carry no information about you or your repositories; like any web request, GitHub sees your IP address. The Microsoft Store version does not make them: the Store updates it.
  • Links you open. Pages such as a repository's web page or the Git download page open in your browser.
  • Commit messages with Codex, only if you turn them on. This is off by default and set per workspace. When it is on and you press Generate with Codex, Alfa Git gives the staged changes of that repository to the Codex CLI installed on your computer, which sends them to OpenAI with your own ChatGPT account to suggest a message. OpenAI's terms and privacy policy apply to that request. Alfa Git itself sends nothing and keeps no copy.

Nothing else: no usage statistics, no crash reports, no identifiers.

This website

  • alfagit.com uses no cookies and no analytics.
  • It is served by GitHub Pages through Cloudflare, and loads fonts from Google Fonts. Those providers receive your IP address and browser details to deliver the page, under their own privacy policies.
  • To link the download buttons to the latest files, the page asks GitHub for the latest release.
  • The operating system tab you pick in the download section is remembered in your browser's local storage, on your device only.

Children

Alfa Git is a developer tool and is not directed at children. It collects no data from anyone, including children.

Changes

If this policy changes, the new version is published on this page with a new date.
